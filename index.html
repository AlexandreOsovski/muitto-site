MUITTO

Zero dependencies. Maximum clarity.

A minimalist, zero-dependency test runner for TypeScript. Fast, lightweight, and built to be read — not just executed.

Get started
$ npm install --save-dev @aleosovski/muitto
Why MUITTO

Focus on what matters.

No plugins to configure, no build file to maintain. Install it and run.

⚡

Zero configuration

Discovers test files automatically from sensible patterns. Works right after install.

◈

Visual diffs

When a test fails, you see exactly what was expected and what was received — no noise.

↻

Watch mode

Re-runs the suite automatically on save, watching the whole project — not just test files.

✓

Full matcher set

toBe, toEqual, toThrow, mock matchers, asymmetric matchers, and more.

◐

Mocks & spies

Create mock functions, spy on existing methods, and control returns, resolutions and rejections.

◷

Fake timers

Control time in your tests: advance timers, run pending callbacks, no real waiting.

☙

Snapshots

Regression tests persisted to disk, compared across runs and commits — not just within one run.

▤

Parameterized tests

it.each to run the same suite against many inputs, with auto-generated names.

▣

CI-ready reporters

json and junit, ready for GitHub Actions, GitLab CI and Jenkins.
